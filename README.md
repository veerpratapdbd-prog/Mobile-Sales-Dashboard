# 📊 Mobile Sales Dashboard

An interactive **Mobile Sales Dashboard** created using **Microsoft Excel** and **Power BI**.  
It visualizes mobile sales data across multiple dimensions such as city, month, brand, model, and payment method.
---

## 🧠 Project Overview
This dashboard provides a comprehensive view of mobile sales performance.  
It helps in analyzing:
- Total sales revenue
- Quantity sold
- Average price
- Transactions by city, month, and model
- Payment methods used
- Customer ratings and feedback
---

## 🧩 Tools & Technologies Used

- **Microsoft Excel** – Data cleaning and preprocessing  
- **Power BI** – Data modeling, relationships, and interactive visualizations  
- **DAX (Data Analysis Expressions)** – Custom calculations and KPIs  
- **Power Query** – Data transformation and filtering  
---

## 📈 Key Insights Displayed
1. **Total Sales, Quantity & Average Price** KPIs  
2. **Sales by City** (Map Visualization)  
3. **Monthly Sales Trend** (Line Chart)  
4. **Ratings by Status** (Bar Chart)  
5. **Transactions by Payment Method** (Pie Chart)  
6. **Sales by Mobile Model** (Horizontal Bar Chart)  
7. **Sales by Day of the Week** (Line & Bar Combo Chart)  
8. **Brand-wise Performance Summary Table**
---

## 🎨 Dashboard Highlights
- Clean, minimal, and user-friendly UI  
- Filter options for:
  - Mobile Model
  - Payment Method
  - Brand
- Month-wise slicers for time-based analysis

## 🚀 How to Use

1. Download the `.pbix` file from this repository.  
2. Open it in **Power BI Desktop**.  
3. Refresh the data if needed and explore filters interactively.
